# JSON Output
For parameters you are creating a paramters name with a default values.

```
{
    "Param1": Integer 0-13
    "Param2": Integer 0-13
    "Type": String of the available types. From './output-types.md'
}
```

# Actions
To create the set of parameters you can create anywhere between 0-3 parameters. If one paramerter is created it can only be Param1 or Type, If 2 are created it must be Param1 & Type, and if all 3 are create then use all 3. Default values are random.
