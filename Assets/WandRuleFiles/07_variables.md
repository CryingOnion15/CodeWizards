# JSON Output
For variables you are creating a variable name with default value.

```
{
    "Var 1": Integer 0-100
    "Var 2": Integer 0-100
    "Var 3": Integer 0-100
}
```

# Actions
To create the set of variables you can create anywhere between 0-3 variables. They should just be use in order. Var 1 when one is created. Var 1 and Var 2 when two are create. All 3 when three are created.
